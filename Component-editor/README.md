# Component-editor — студия компонентов EWR

Небольшой автономный проект для перерисовки исходных иконок EWB в чистый SVG
и экспорта готового компонента в отдельную папку.

## Рабочий процесс

1. **Показать элемент.** Нажмите «🗂 Библиотека элементов» (или откройте
   `index.html#library`). Галерея показывает `828` элементов, нарезанных из
   исходных BITMAP-полос EWB (`extracted_assets/BITMAP30xx–33xx_1.bmp`).
   Каждый элемент — это пара: `png/…` (иконка) + `svg/…` (элемент в редакторе,
   стартовая SVG-обёртка для обводки).
2. **Описание.** Выберите элемент и заполните поле «Описание объекта» —
   оно попадёт в `manifest.json`, `description.txt` и `<desc>` SVG.
3. **Фото пользователя.** «Загрузить фото…» кладёт ваш снимок под холст
   как полупрозрачный референс. Фото сохраняется рядом с компонентом.
4. **Рисование SVG.** Обведите элемент линиями/прямоугольниками/эллипсами,
   добавьте порты (`P`) и поля значений (`N`).
5. **Экспорт.**
   - **«Сохранить в проект»** — прямая запись в `Component-editor/components/<id>/`
     (нужен локальный сервер `npm run studio`).
   - «Экспорт в выбранную папку…» — выбор каталога через File System Access API.
   - «Скачать …» — запасной вариант отдельными файлами.
   ```
   <id>/
     symbol.svg        — готовый векторный элемент (viewBox = область обрезки)
     icon.png          — иконка элемента (рендер symbol.svg)
     manifest.json     — id/имя/категория/описание/иконка/символ/параметры/порты
     description.txt   — человекочитаемое описание
     source.png        — исходная иконка EWB (если выбрана в библиотеке)
     reference.jpg/png — загруженное фото (если было)
   ```

## Готовые компоненты в библиотеке

Если компонент уже нарисован (есть `manifest.json` + `symbol.svg` в
`Component-editor/components/`, корневом `components/` или `Site/components/`),
его плитка в галерее получает зелёную рамку и метку **✓ «сделан»**
(`GET /api/drawn-components`).

Кнопка у такого элемента называется **«Открыть на редактирование»**:
`symbol.svg` загружается на холст, порты берутся из `manifest.json`, а
«Сохранить в проект» пишет изменения обратно в ту папку, откуда компонент был
открыт. Иконка при этом не перезаписывается.

## Режим «Слияние»

Вкладка **«Слияние»** кладёт нарисованный SVG в уже существующий элемент
палитры EWR. Интерфейс категорий скопирован из `Site/logic/js/interface.js`
(сам Site не меняется): те же id категорий и номера плиток BMP.

1. Выберите категорию (`Компоненты`, `Приборы`, `Текст`, …) и элемент-плитку
   (`resistor`, `capacitor`, `multimeter`, …).
2. Задайте масштаб SVG в процентах или нажмите **«Вписать в размер элемента»** —
   размер берётся из `manifest.json` выбранного элемента.
3. **«Слить SVG в элемент»** записывает
   `Site/components/<id>/symbol.svg`.

Иконка остаётся прежней (BMP-плитка палитры), `manifest.json` существующего
элемента не меняется. Если папки элемента ещё нет, создаётся минимальный
манифест с размерами и портами из редактора. Для записи нужен `npm run studio`;
список палитры отдаёт `GET /api/palette`, запись — `POST /api/merge-symbol`.

## Динамические поля значений

Инструмент **«Ⓣ Поле значения»** (`N`) вставляет `<text data-slot="…"
data-default="…">`. `data-slot` — имя параметра, которое движок EWR
подставляет при отрисовке схемы; значение по умолчанию видно на холсте и
уходит в `manifest.json → parameters`.

## Перегенерация нарезки

Нарезка не требует зависимостей (Node >= 18):

```bash
node Component-editor/tools/slice-elements.mjs
```

Скрипт читает `extracted_assets/BITMAP30xx–33xx_1.bmp`, делит полосу на
ячейки (24 px для высоких лент, 16 px для низких), делает серый фон
прозрачным и пишет на каждый элемент пару `png/` (иконка) + `svg/`
(элемент в редакторе), а также общий `elements/index.json`.

## Запуск и прямое сохранение

Для прямой записи в проект запустите встроенный сервер (без зависимостей):

```bash
npm run studio
# → http://127.0.0.1:5501/
# сохранение: Component-editor/components/<id>/
```

Сервер слушает только `127.0.0.1`, отдаёт статику из `Component-editor/` и
принимает `POST /api/save-component`. Другой порт/папка:

```bash
npm run studio -- --port 5502 --out /путь/к/компонентам
```

Обычный Live Server (порт `5501`) тоже подходит для рисования, но прямая
запись в этом режиме недоступна — останутся выбор папки и скачивание.
`fetch('elements/index.json')` требует HTTP, по `file://` галерея не работает.
