# P2.2 — BJT (Gummel-Poon: NPN/PNP, area, temp)

> Родительский план: `docs/engine/PLAN-CLONE.md` (§4, фаза P2)
> Статус: `planned`
> Начат: 2026-11-25 · Обновлён: 2026-11-25
> Артефакты: `Site/engine/spice/devices/bjt.js` (появится), `tools/oracle/{corpus,golden}/bjt_*.json` (после снятия деков)

## Цель

Портировать биполярный транзистор (BJT) SPICE3F4/XSPICE 1:1 (`vendor/xspice-1-0/src/sim/DEV/BJT/`):
модель Gummel-Poon (NPN/PNP), `DEVsetup`, внутренние узлы, DC/TRAN-загрузку,
AC-нагрузку, транзитное время, температурную подстройку, сходимость (`BJTconvTest`),
задачи/breaks, ask. Получить паритет с оракулом на характерных схемах.

## Границы (что не входит)

- Noise/Disto/PZ/Sensitivity-хуки (`BJTsSetup`/`BJTsLoad`/`BJTsUpdate`/
  `BJTsAcLoad`/`BJTsPrint`) — фаза P3.
- Цифровые модели (цифровые симуляции транзистора) — отдельно.
- JFET/MESFET — P2.3.

## Источники и референсы

- `vendor/xspice-1-0/src/sim/DEV/BJT/` — основной источник (XSPICE-редакция):
  `BJT.c` (структуры/таблицы), `BJTsetup.c`, `BJTask.c`, `BJTload.c`,
  `BJTsLoad.c`, `BJTsUpdate.c`, `BJTsSetup.c`, `BJTsAcLoad.c`, `BJTsPrint.c`,

  `BJTmParam.c`, `BJTmAsk.c`, `BJTpzLoad.c`, `BJTgetic.c`, `BJTdelete.c`,
  `BJTdestroy.c`, `BJTacLoad.c`.
- `vendor/xspice-1-0/src/sim/include/BJTdefs.h` — `sBJTinstance`, `sBJTmodel`, 21
  состояний (`BJTvbe…BJTnumStates=21`).
- `vendor/xspice-1-0/src/sim/DEV/DEVsupport.c` — `DEVpnjlim` (критерий ограничения
  pn-перехода у BJT), `DEVpred`, `DEVlimvds`.

- `tools/oracle/{run.mjs,shim.py}`, `tools/oracle/corpus|golden/*.json`.

- Новые квирки — в `docs/re/engine-quirks.md` с ID (`Q-Bxx`).
