## Цель

Дать возможность перерисовать исходные иконки компонентов EWB в чистый SVG:
показать исходный элемент, заполнить описание, загрузить фото-референс,
нарисовать символ с портами и динамическими полями значений и экспортировать
его в отдельную подпапку рядом с проектом.

## Границы (что не входит)

- Автоматическое распознавание/векторизация растровых иконок — обводка вручную.
- Запись в `Site/components/` без участия пользователя (экспорт — через выбор папки).
- Изменения движка, нетлиста и производственного конвейера сборки.
- Полный набор имён/категорий EWB: элемент получает id вида `ewb-3001-01`,
  понятное имя и описание задаёт пользователь.

## Источники и референсы

- `extracted_assets/BITMAP30xx–33xx_1.bmp` — исходные ленты иконок (read-only).
- `Component-editor/` — существующий редактор SVG (холст, порты, обрезка, экспорт).
- `Site/components/*/manifest.json` — формат манифеста компонента.

## Шаги / чекпойнты

- [x] Нарезка BITMAP-полос: 4-bpp BMP → пара «иконка PNG + элемент SVG»
      на каждый элемент → `elements/{png,svg}/` + `elements/index.json`
      (828 элементов, 68 полос).
- [x] Галерея: поиск, фильтр по полосе, превью, описание (localStorage).
- [x] Фото-референс пользователя: загрузка, превью, подложка на холсте.
- [x] Инструмент «Поле значения» (`N`): `<text data-slot data-default>`.
- [x] Экспорт в выбранную папку через File System Access API:
      `<id>/{symbol.svg, icon.png, manifest.json, description.txt, source.png, reference.*}`.
- [x] Прямое сохранение в проект: `npm run studio` → `POST /api/save-component` →
      `Component-editor/components/<id>/`.
- [x] Запасное скачивание `symbol.svg` + `icon.png` + `manifest.json`.
- [x] Тесты нарезки/PNG и документация (`Component-editor/README.md`).
- [x] Режим «Слияние»: скопированный из EWR интерфейс категорий/плиток,
      выбор существующего элемента палитры, масштаб SVG (в т.ч. «вписать»),
      запись `Site/components/<id>/symbol.svg` без изменения иконки и манифеста.
- [x] API студии: `GET /api/palette`, `POST /api/merge-symbol`, отдача
      `Site/img/title/*.bmp` и `Site/components/*` для превью.
- [x] Готовые компоненты: `GET /api/drawn-components`, пометка «сделан» в
      галерее, открытие `symbol.svg` для правки, сохранение обратно в исходную
      папку с сохранением иконки.

- [x] Масштаб SVG задаётся в процентах и режимом «вписать в размер элемента».
- [x] В галерее видно, какие элементы уже нарисованы; их можно открыть,
      отредактировать и сохранить обратно в исходную папку.

## Риски и квирки

- PNG получены из оригинальных иконок EWB → те же лицензионные риски, что у
  `Site/img/` (решение владельца, см. `DISCLAIMER.md`).
- File System Access API есть не во всех браузерах → запасное скачивание файлов.
- `fetch('elements/index.json')` требует HTTP (Live Server), не `file://`.
